# How to Apply for Leave

Submit planned leave in the HR portal before making non-refundable travel arrangements. The request should identify the leave dates, leave type, and a short handover note. Sick leave should be entered as soon as practical and may require supporting documentation under the applicable company policy.

1. Open the HR portal and choose Leave from the employee menu.
2. Select New request and choose annual, sick, unpaid, or another available leave type.
3. Enter the first and last day. Check the working-day total shown by the portal.
4. Add a handover note naming the colleague covering urgent work.
5. Submit the request and confirm that it shows Pending manager approval.

The manager receives the request automatically. A request is not approved until its status changes to Approved. For a correction, withdraw the pending request and submit a new one. Questions about balances, payroll impact, or leave types belong with HR support; questions about the approval route belong with the employee’s manager.
